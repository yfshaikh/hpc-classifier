branch-misses - modern CPUs guess the path the code will take and speculatively load and execute instructions to be faster. if they miss, the CPU must start over.  Spectre attacks trick a processor into speculatively
executing instructions that shouldn’t be executed. Consequently, the attacks are able to read memory addresses not belonging to the adversary.

cache-misses - Flush attacks repeatedly flush cache lines while measuring the execution time of the cache flush instruction. I expect a jump in cache misses

bus-cycles - Rowhammer attacks exploit DRAM-based devices by repeatedly accessing a row of memory, thus resulting in bit flips in adjacent rows which can damage a system. This will cause a jump in bus cycles

instructions - Certain malware variants engage in aggressive "busy loops" (such as mining cryptocurrency, decrypting payloads, or obfuscating code). This highly repetitive execution forces a surge in the number of instructions retired per clock cycle.
